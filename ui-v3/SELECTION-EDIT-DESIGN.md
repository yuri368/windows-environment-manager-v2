# V3 统一演示计划实施说明

本轮依据 docs/architecture/V3_MINIMAL_CONTRACT_V3_1.txt；仅浏览器演示。开发/预览主目录仍为 `H:\Yuri368\环境变量配置V3`，Git镜像为 `H:\Yuri368\环境变量配置V3-git\ui-v3`。

## 唯一计划来源

沿用现有 `DemoPlan` 名称，它现在返回契约定义的不可变 ChangePlan，未另造平行模型。`build` 从演示快照、选定值和模式生成 `matchResult`、`before/after`、`operations`。快照区分不存在与空字符串，并保存类型及对应目标版本。

工作台按变量与快照/目标输入缓存当前有效计划；匹配计数、选定值标记、实际待追加候选和预览都读取计划。普通输入的 `SelectionChange` 仅描述基准选定值与当前选定值，不推测 Windows 元素替换。

明确的 Windows 元素编辑复用原有稳定行身份审计。`buildElementEdit` 将一次审计转为冻结计划；编辑行和原新对照读取计划的审计结果，确认应用按计划的最终 after 更新演示值。历史保留同一冻结计划、确定操作、真实 before/after，后续编辑不能改变已保存记录。

## 确认与失效

预览保存冻结计划及生成时的目标状态。确认前检查对应目标的 exists/raw/type/revision 和选定值、模式、作用域、special；改变时拒绝旧预览并要求重新预览。无关目标变化不使计划失效。同目标批量操作仍按预览顺序计算前后结果，已有共享replace冲突与append自定义排序限制保持。

取消、关闭、无变化均不产生变化历史。append空目标不创建不存在的变量；元素编辑器明确新增空行才创建空字符串。

## 展示

配置左栏仅留应用和方案两个独立滚动区域；中间表格支持点击、Enter/Space、方向键和Home/End选择变量，右侧属性跟随。

Python Scripts→Scripts1 普通输入显示“选定值已修改”，保留原选定值→当前选定值。实际append计划明确保留旧Scripts、追加Scripts1。明确编辑Windows行时才显示替换。待追加标签与候选由确定insert操作生成；重复选定项仍逐项统计匹配，但同normalized缺失项只标首次实际插入项。

暂缓增加独立的“选定值元素编辑”入口，避免与本轮计划收敛混在一起。
