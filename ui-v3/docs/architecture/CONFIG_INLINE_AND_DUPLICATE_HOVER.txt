2026-10-15 负责人最新需求：行内配置编辑与重复元素悬停

范围
负责人在 TOML 样式提醒后明确要求补齐 choices，沿用 V2 文件规则，融合中部与右侧编辑区；另明确要求重复标签对应的同值元素跨修改前后联动。此前 TOML 暂缓要求由本次明确需求覆盖。
只改 V3 浏览器演示。V2 只读作为格式参考，不迁移其执行代码；不读写实际环境或原 TOML。DemoPlan、应用、Audit、历史格式和稳定 occurrence ID 契约继续适用。

配置界面
应用/方案导航保留；变量本身展开行内表单，不另设右侧属性栏。默认值与候选标签/值直接编辑。候选可添加、删除、上下移动。较宽窗口并列默认值和候选；窄窗口纵向排列，导航可收起，主画布单独滚动。
支持 default_value、scope、mode、special、editable、choices。readonly 只约束运行时自由输入，配置字段仍可编辑；已配置候选、默认值和已保存值仍可选择。
候选修改/移动按明确行操作协调当前来源。还原配置按候选原始 label/value 重新定位，若已不在恢复后的候选列表则回到默认值，不保留错误的旧索引。
文本使用 textarea 并映射原始换行边界，保留未编辑 CRLF/CR/LF 和前导换行。工作台共用同一映射。
完整原文已直接可编辑，元素预览与选定值信息默认折叠，避免重复占空间。

V2 格式
导出应用表和方案表；应用内 default_option 指向方案；每个变量含 default_value、scope、mode、editable，按需要含 special 与 choices=[{label,value}]。同名双作用域使用同一键的两记录数组。
候选标签非空，label/value 分别按完整字符串检查重复；不修剪值或合并大小写。字符串禁止 NUL，按 V2 的 UTF-16 上限检查；Special 仅 replace，且同一目标各方案一致。无效草稿可编辑、查看原文与差异，导出暂停。
导出专用 TOML 引用保留反斜杠、引号与控制字符，DEL 使用 Unicode 转义。不输出 savedValue/source/custom、浏览器编辑来源或模拟 Windows 数据。导出新文件，不覆盖输入文件；不实现原文件解析/导入。

重复悬停
保留 is-related-highlight 按既有 ID 映射同一 occurrence；增加独立 is-duplicate-highlight 展示层。悬停有重复标记的元素时，按所悬停那一侧的精确原始值，在当前对照/编辑器范围跨栏联动所有相同原文元素，含空字符串。空格、大小写、CRLF 均参与精确相等。
原值 A 改为 B 后，同一 ID 的原值与新值仍按身份联动；重复组根据实际悬停原值 A 或新值 B 分别选择。幽灵可接收高亮但不增加有效重复数；整体 Special 不推断分号内部重复。
移出清除重复组并恢复焦点身份联动。只改 class，不重建节点、不改字符串、顺序、结果、计划或历史；reduce-motion 使用静态反馈。

验证范围
专项 DOM 16 项重复悬停、14 项配置编辑。完整 npm test 29 脚本 556 检查通过。实际 Chrome 鼠标验证前值 A 组 6 处、新值 B 组 5 处和离开清理；桌面与 600px 配置布局截图。浏览器编辑后的 TOML 经 V2 parse_config 成功解析 13 应用/23 方案/60 变量。
