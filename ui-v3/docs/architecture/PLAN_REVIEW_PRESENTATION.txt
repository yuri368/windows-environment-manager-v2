V3 执行前审阅展示补充 — 2026-10-16

范围：浏览器离线演示的只读 UI。负责人授权自主改进；设计与交互边界经过四轮 Astra 分析/复核，证据在 design-evidence/astra-polish-2026-10-16/。

1. 预览摘要和逐目标状态只消费当前 modalAction.rows 中的冻结 plan。不得根据 dirty、匹配率、ghost 数量重新决定操作、After、删除资格或确认门槛。
2. plan.valid=false 或任一参与成员为尚未实现排序确认的 append 时，整批仍不可应用。撤销仍只说明范围，不执行。没有 operations 的有效计划继续允许确认成功选择；不虚构写入或新增修改历史。
3. duplicate/shared/continuity 属于未解决删除提示，不自动阻塞安全操作。部分应用继续保留原输入、基线、删除意图与部分完成历史。零操作且有提示时准确说明当前值未改变。
4. duplicate 可来自原匹配或当前匹配，不能断言当前必有多个副本；shared 不推断保护者身份；continuity 不承诺刷新或相同文本重现可恢复资格。stale 展示已知上下文字段，conflict 展示实际参与方案和模式。
5. 目标导航按 [scope, canonicalName] 定位，不改变 rows 顺序、请求范围、勾选、计划、版本或审阅状态。User/System 同名目标分离。同一目标多个成员仍合并展示。
6. 返回工作台检查仅关闭预览并定位首个成员的应用/方案/变量；保留批量勾选、输入和编辑会话。工作台新增预览动作明确使用原有单方案/批量范围；查看对照仅改变阅读位置，不编辑值。replace 继续不能从工作台打开 Windows 元素编辑器。
7. 预览刷新继续单独 review→confirm。索引、原文展开、焦点和公告均不算审阅。相关状态变化被确认点击发现时只刷新并返回；同步全目标验证及实际提交之间仍无 await。
8. 原文展开按 canonical target 保存。纯展示重绘可按目标、区域、现有 relatedKey 还焦；跨版本没有可靠 occurrence 映射时回退同目标标题，不用相同文字或下标猜身份。焦点原在页脚则保持，确认因刷新禁用时移到标题。
9. 预览只有 body 滚动，标题与操作栏可见；600px 下前后值堆叠、长路径断行、页脚说明换行。沿用原 token 颜色、元素审计和辅助技术导航，不新增持续动画或运行依赖。

本文件不修改 SEAMLESS_REFRESH.txt 的核心计划、连续性、安全执行与编辑器草稿规则。没有接入 Python、Windows 注册表、WebView 或真实系统监听。
