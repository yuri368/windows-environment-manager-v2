# Environment Manager V3 UI Data Contract

版本：V3.0

状态：UI数据契约规范


==================================================

# 1. 设计目标


本文件定义：

核心逻辑层

与

UI展示层

之间的数据边界。


目标：

确保：

- 工作台
- Windows环境页面
- 元素编辑器
- 历史页面


使用统一数据来源。


==================================================


# 2. UI核心原则


## 原则1：

UI不负责计算状态。


禁止：

UI代码：

判断字符串是否存在。

计算新增。

判断替换。



正确：

核心层生成：

MatchResult

ChangePlan



UI只展示。



--------------------------------------------------


## 原则2：

UI展示用户意图和系统事实。


事实来源：

WindowsSnapshot


用户目标：

SelectedConfiguration


变化：

ChangePlan



==================================================


# 3. UI数据来源


所有页面只能读取：


## CurrentState


当前系统状态。


来源：

WindowsSnapshot



--------------------------------------------------


## TargetState


用户目标。


来源：

SelectedConfiguration



--------------------------------------------------


## MatchResult


匹配结果。


描述：

当前是否满足目标。



--------------------------------------------------


## ChangePlan


变化计划。


描述：

达到目标需要什么变化。



==================================================
