# 导航与恢复反馈 · 2026-10-15

承接四区域铭牌版本 2357ed5，在既有 UI 合同内继续完善尚未覆盖的导航、筛选恢复和局部反馈。沿用负责人选择的较鲜明动效；不更改计划、匹配、Apply、配置导出格式或历史模型。

## 本轮行为

- 搜索旁增加清空入口；非输入法组合状态的 Escape 只清除搜索文字，保留当前筛选。零匹配提供“清除搜索与筛选”，保留当前应用、勾选和数据。
- 显示当前结果数量；当前应用被筛选隐藏时提供“定位当前应用”，清除视图条件并聚焦原应用，播放一次定位反馈。
- 应用列表与配置应用/方案列表支持 ↑↓、Home、End 移动焦点；Enter/Space 沿用原生按钮激活。修饰键组合不被拦截。仅移动焦点不更换选定内容。
- 应用列表重绘保留滚动。配置导航列表保留滚动；同一应用/方案内保留内容区域位置，同一变量属性重绘保留检查器位置；更换应用/方案的内容从顶部开始，更换变量的检查器从顶部开始。
- 配置视图补齐 tablist/tab/tabpanel、aria-selected、唯一激活标签 Tab 入口和左右键/Home/End 切换。
- “仅看未匹配”为空时可返回全部变量，焦点回筛选框。Windows 对照折叠按钮同步 aria-expanded/aria-controls，并增加箭头和一次性展开动效。
- 复制成功后按钮有短暂成功反馈；在 await 前固定源文本与按钮，切页期间完成的复制不会错误标记新视图或报空按钮失败。Clipboard 被拒绝时保留手动复制提示。
- 新反馈继续集中在 surface-ui.css；更深的非激活导航文字改善对比。窄屏空搜索结果保留直接可见的恢复按钮；prefers-reduced-motion 下关闭新增空间动画。

## 验证

- 最终原有回归：25 组、487 项通过，详见 regression.txt。
- 新增状态/焦点专项：19/19，通过记录见 navigation-checks.json。可在项目根目录运行 `node design-evidence/ui-navigation-2026-10-15/verify-navigation.cjs`。覆盖恢复不改数据、输入法 Escape、按键不误激活、滚动上下文、tab 语义、Clipboard 成败与异步切页。JSDOM 不证明真实滚动几何。
- Chrome 独立新 QA 标签页，先前已打开的演示页未重置。真实键盘检查：列表 End 只定位，Enter 才激活；应用侧栏激活前后 scrollTop 均为 448.6667；修正后配置侧栏末项激活前后均为 62.6667。属性重绘时 cfgSpecial 保持焦点，检查器 scrollTop 保持 261.3333。
- 修正了浏览器才暴露的几何问题：最初底部键盘提示增加列表高度，激活后滚动由 90 回落到 62.6667；将提示移到组标题，不占列表滚动内容。修正后的实测见上一项。
- 实际 Chrome 确认配置 tab 左右键与 panel 名称同步、复制完成后 data-copy-state=copied、空变量筛选恢复后为 2 行且焦点回 onlyMismatch。

- 临时模拟减少动态效果，展开对照时 computed animation-name=none；已清除模拟。最终读取显示尺寸恢复到 1707×852，error 级页面日志为空。
- Sol 只读复核发现并确认修正：新应用/方案不继承旧内容滚动、异步复制不污染后续视图。此项是源码复核，与浏览器结果分别记录。
