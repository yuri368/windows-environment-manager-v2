负责人反馈只有原条目编辑、缺少新增按钮。现补齐“新增应用”“新增方案”“新增变量”，与既有“添加候选值”组成完整创建入口。沿用紧凑桌面布局，在中间编辑区使用行内表单；取消及 Escape 不提交。创建成功聚焦新变量默认值，继续支持原始值、候选值、模式和作用域编辑。

新应用连首个方案、首个变量一起创建，首方案为默认；新方案连首个变量一起创建，原默认方案不变。名称、作用域和模式检查后，构造完整候选配置并校验，成功才一次加入。失败不残留节点。同目标 Special 配置沿用，表单明确显示整体处理及 replace 模式。

配置原始字段现在按 WeakMap 关联原对象，避免新增后的下标错位。新增父节点包含子树，差异不重复计数；还原移除新增条目，修正导航与批量勾选，保留原对象和未受上下文改变影响的运行草稿。新增不修改模拟 Windows 或历史，仍通过工作台原预览流程应用。
