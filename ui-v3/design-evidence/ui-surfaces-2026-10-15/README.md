# 四区域 UI 与动效续作 · 2026-10-15

本轮承接此前未接入的 value stream helpers，覆盖应用预览、Windows 快照、操作历史和配置属性。负责人选择“整体更炫酷，展开、切换和联动效果更明显”。沿用现有铭牌风格；交互动画仅用于展示反馈。

## 交付

- 应用预览：接上冻结计划的 comparisonMarkup，前后并排、窄屏上下排列；悬停/Tab 聚焦按既有 occurrence 身份联动。新增元素裁切落位、对应铭牌定位反馈。完整原始字符串独立展开，仍使用 textContent。撤销只显示事实说明，原有禁用与冲突规则保留。
- Windows：原始快照与直接编辑入口保留；每项下方增加“快照结构”，展开带序号、重复/空元素提示的中性铭牌。Special 整体字符串不拆分。此页不接受方案匹配、待增删或冲突覆盖。
- 历史：展开前后记录快照的结构视图，带一次性铺展、时间轴反馈与“查看/收起详情”切换。原始值可独立展开，既有审计条目保留。结构视图不构造跨值对应关系，不使用“待追加/待删除”等未来操作状态。
- 配置：默认值输入实时更新结构预览，空/重复项与整体字符串可辨识；默认值、作用域、模式、Special 的局部修改标记与原有总计数同步。控件名称保持稳定；输入过程不重绘 textarea，不抢走焦点。
- 新样式集中在 surface-ui.css。动效包括展开裁切、有限分批呈现、联动定位、新增落位与历史时间轴反馈；prefers-reduced-motion 下关闭空间动画。长列表延迟最多 168ms，没有新增循环扫描。
