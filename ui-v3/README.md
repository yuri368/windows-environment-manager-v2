# 环境变量方案管理器 V3

V3 已实现独立 Python 本地服务、持久配置与草稿、冻结计划执行和恢复，并生成 Windows x64 候选安装包。界面沿用已接受的紧凑网页 UI，由本地服务提供。当前仍是候选版，干净 Windows VM、真实 System/UAC、多用户和原生 DPI/IME/拖动验收尚未完成。

- [运行与数据说明](docs/product-v3/RUNNING.md)：安装包启动、源码隔离运行、配置/草稿/历史的位置与操作流程。
- [构建与候选包](docs/product-v3/BUILD.md)：当前包、SHA256、依赖与许可证。
- [实际验收记录](docs/product-v3/ACCEPTANCE.md)：File、DefaultBox 和真实浏览器证据，以及剩余门槛。

正式页面入口为 `index.html`，通过 V3 EXE 或 `python -m envmanager_v3` 启动。`temp.html` 保留为历史浏览器演示，下面的示例数量和旧回归计数均属于演示阶段。

## 2026-10-16：执行前审阅与交互完善

预览现在先说明实际变更、值不变、删除保留和整批阻塞，再按目标展示当前值与结果。目标索引支持键盘定位；重复、共享、原元素无法确认等情况分别说明原因，可返回工作台检查。工作台变量名提供“查看对照”，计划提示可进入原有单方案或批量预览。

当前值刷新后保留原文展开和合理焦点；更新预览仍需先审阅、再确认。无值变更时可以确认方案选择；有未解决删除时继续保留输入和意图，不报告全部完成。600px 预览使用单一滚动区，标题和操作栏保持可见。

本轮完整回归 32 组、606 项通过，另有 Linux Chromium 无头浏览器 13 个流程通过。四轮 Astra 方案/复核、截图、复现脚本和实际测试日志见 [本轮交付报告](design-evidence/astra-polish-2026-10-16/REPORT.md)。这些结果验证浏览器演示，不代表真实 Win11、注册表或 UAC 已验收。

## 最新交互改进

- “待应用”按选定字符串与方案基准值的精确差异计算，改回原值或选择同值来源会消除标记；检测列始终独立显示匹配结果。
- 基准值初始为方案默认选定值，模拟应用成功后更新为该次选定值。它与 Windows 快照分开，因此匹配状态与是否存在输入修改不相互覆盖。
- 元素列表的匹配项使用浅绿背景；替换、新增和移动使用小标签。前后对照同步显示状态，删除项以灰色划线保留，实际结果字符串只包含仍有效的元素。
- 被准备方案整体替换的 Windows 当前值显示“将替换”；它表示待执行意图，不表示已修改 Windows。

- 元素编辑器可还原打开时的值；删除最后一项后焦点回到新增入口。
- 应用、勾选框、配置方案、变量与属性重绘后保留键盘位置，当前对象有明确的辅助技术标识。
- 配置修改的默认值、作用域、模式和整体处理属性均纳入修改计数、差异及还原。
- 还原配置不改变演示 Windows 快照、待应用输入或历史记录。
- 长标题与弹窗工具栏有局部换行适配；Chrome 已按 1360×680、1112×556、800×600 视口检查，Windows DPI 与其他浏览器尚未验证。

## 协作约定

GitHub 分支 `v3/web-ui-prototype` 是网页原型的版本记录。审查应引用具体提交和 `ui-v3/` 文件。原项目的 Python 源码作为仓库基线保留，网页原型没有调用它。真实环境接入需另行设计和授权；此分支不直接合并 `main` 或创建安装包。

## 三值对照（V3.3）

当前选定值、Windows 当前值和应用后的值使用同一种元素色框。确定追加项标“待追加”；确定删除项在当前值原位置与结果对照中划线保留。结果对照的删除项仅是视觉标记，下方“最终写入字符串”与预览、模拟应用及历史读取同一冻结计划，不含删除项。按 occurrence 关联悬停与键盘焦点，不按相似文本配对；重复元素独立保留。宽屏并排、窄屏堆叠。

删除全部实际元素会使变量不存在；保留原始空元素或明确创建一个空元素则保留存在的空值。同目标批量请求混用普通与 Special 类型时阻止确认。

## 编辑器方案建议与本次编辑（V3.4）

方案建议集中于未采纳区域；点击加减号只将建议采纳到当前编辑列表。元素行、前后对照和底部摘要仅展示当前实际编辑；未采纳建议不写入应用结果或历史。手动编辑、还原、取消与仅采纳部分建议均使用既有稳定元素审计计划。工作台三值对照保持V3.3语义。
