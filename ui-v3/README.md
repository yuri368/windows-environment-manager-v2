# V3 Web UI Prototype

此分支维护环境方案管理器的网页 UI 与展示交互。当前不是 V3 正式产品，未接入 Python、Windows 注册表或 WebView 桥接。

## 查看界面

下载或检出此分支，将 `ui-v3/` 的文件放在一起，用浏览器打开 `temp.html`。

- `temp.html`：工作台、方案配置、Windows 演示环境、历史与预览。
- `ui-polish.css`：紧凑界面、方案选择器、配置方案分组。
- `elements-ui.css`：匹配元素高亮与元素编辑弹窗。
- `windows-elements.js`：两个页面共用的演示元素编辑器。
- `demo-configs.js`：新增六组虚构示例与演示快照。

当前提供 **13 个应用、23 个方案、60 条变量记录**。建议搜索 Node.js、CUDA、中文长路径或“列表与空值”开始体验。各示例的操作步骤见 [EXAMPLES.md](EXAMPLES.md)。

页面不需要安装依赖或运行构建。编辑、排序、删除和应用只改变本次页面会话内的演示数据；刷新页面会重置这些数据。示例 TOML 是设计展示格式，不能当成正式配置序列化器。

## 最新交互改进

- “待应用”按选定字符串与方案基准值的精确差异计算，改回原值或选择同值来源会消除标记；检测列始终独立显示匹配结果。
- 基准值初始为方案默认选定值，模拟应用成功后更新为该次选定值。它与 Windows 快照分开，因此匹配状态与是否存在输入修改不相互覆盖。
- 元素列表的匹配项使用浅绿背景；替换、新增和移动使用小标签。前后对照同步显示状态，删除项以灰色划线保留，实际结果字符串只包含仍有效的元素。
- 被准备方案整体替换的 Windows 当前值显示“将替换”；它表示待执行意图，不表示已修改 Windows。

- 元素编辑器可还原打开时的值；删除最后一项后焦点回到新增入口。
- 应用、勾选框、配置方案、变量与属性重绘后保留键盘位置，当前对象有明确的辅助技术标识。
- 配置修改的默认值、作用域、模式和整体处理属性均纳入修改计数、差异及还原。
- 还原配置不改变演示 Windows 快照、待应用输入或历史记录。
- 长标题与弹窗工具栏有局部换行适配；Chrome 已按 1360×680、1112×556、800×600 视口检查，Windows DPI 与其他浏览器尚未验证。

## 协作约定

GitHub 分支 `v3/web-ui-prototype` 是网页原型的版本记录。审查应引用具体提交和 `ui-v3/` 文件。原项目的 Python 源码作为仓库基线保留，网页原型没有调用它。真实环境接入需另行设计和授权；此分支不直接合并 `main` 或创建安装包。
