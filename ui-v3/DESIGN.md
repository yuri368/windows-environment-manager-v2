# Compact 工作台网页优化

本轮优化已有 HTML 原型，不迁移 Python 后端，不执行真实环境变量操作。

使用者在桌面上准备开发环境方案，主要任务是查看当前方案、编辑运行值、核对实际状态和审阅操作范围。设计采用紧凑两栏，正文 13px、变量值 12.5px、主要辅助说明 12px、控件 32–34px。色彩以纸白、浅灰绿、深色文字、森林绿行动色、琥珀草稿色和红色错误为主。绿色用于检测结果和主要行动；普通选择位置采用浅中性色。

产品概念：应用、方案、变量、作用域、候选值、运行草稿、Windows 快照、变更预览。辨识性结构是“准备方案 → 变量选定值 → Windows 值对照”，每个区域明确数据所属方案。避免巨大状态卡片、多个成功绿色选中块和不同方案变量的平铺。

## 本轮落地

- 工作台保留应用侧栏、变量表和两列值对照，提高文字可读性，整理间距和视觉层级。
- 方案入口正常状态透明，悬停和焦点才显示边界；菜单与入口共用宽度。方向键、Home/End、Escape 和选择后焦点返回可用。
- 最近应用记录与 Windows 检测状态分开呈现，准备方案通过独立选择器显示。
- 配置编辑器默认仅显示当前方案；“全部方案”以独立方案标题、变量数和当前编辑位置区分内容。属性区标注应用/方案/变量归属。
- 属性编辑保留原始字符串，修改当前方案不会同步改掉另一方案。变量行支持键盘选择。
- 模态预览支持焦点留在弹窗内、取消后返回原入口。单应用/批量预览和已有撤销范围入口保留。
- 保留 Windows 环境页、历史页、示例 TOML、差异和导出入口。
- 删除装饰性的假窗口按钮，保留“本地演示 · 未连接系统”标识。原型原有的撤销/自定义排序限制没有移除，不伪造正式业务结果。
- 样式放在 `ui-polish.css`，由 `temp.html` 加载；无生产 npm 依赖或构建步骤。原始文件备份保留于本地，不纳入该分支。

## 2026-10-13：四处批注修正

本轮仅设计 UI 与演示交互。以下所有编辑和“应用”均只更新浏览器会话内的演示快照。

- 工作台 Windows 值对照按元素高亮与准备方案匹配的内容。保留分号、原始空格、空元素和重复元素；特殊值整体对比。浅绿底和下划线只标记匹配内容，不将整段字符串涂绿。
- 工作台对照值、Windows 环境表的值均可双击或按 Enter/Space 打开同一个元素编辑弹窗，并提供可见的“编辑”入口。
- 元素弹窗显示变量名、作用域、示例类型和元素数。支持编辑、增加、删除、上移下移、Alt+方向键排序及拖拽；可展开完整编辑前后字符串。特殊值用整体文本框，不拆分、不提供元素排序。
- 取消或 Escape 丢弃弹窗草稿，原演示快照不变；“应用（演示）”仅更新页面数据并生成演示历史。弹窗焦点循环、取消和应用后的焦点返回均已核查。
- “全部方案”删除“分组”字样。方案标题统一中性灰，名称、变量数和默认/当前编辑标记分区排列；当前变量使用细左边线，避免多个绿色背景竞争。
- 共用组件独立在 `windows-elements.js`，元素样式在 `elements-ui.css`，无框架和运行依赖。修改前页面保留于本地。

已向分支 ChatGPT 架构师说明 UI 范围并获得本轮设计方向确认，完成后汇报 28 项 DOM 检查结果。架构师回复“本轮通过”；此结论为原型设计审查，不替代实际浏览器视觉验收。没有引入后端、桥接或真实环境执行。

## 验证与限制

### 2026-10-13：紧凑色框、同项联动与重复提示

负责人选定保留分号连接的紧凑字符串对照。移动采用可见紫色背景与边框，替换为琥珀、新增为蓝色、删除为灰色加删除线；每项有完整边界，长路径跨行使用 `box-decoration-break: clone`。变更优先级为删除、新增、替换、移动；匹配采用绿色小勾，不覆盖变更主色。编辑和移动并存时保持琥珀主色及移动标签。

原值、新值与编辑行按稳定元素 ID 联动高亮。重复文本和空元素保留独立身份。鼠标悬停优先，离开后恢复输入焦点对应项；悬停只切换关联 class，不重新计算差异、重建节点、排序或修改字符串。正常编辑重绘后重现焦点联动；关闭移除监听，重新打开使用新会话。对照元素不加入 Tab 顺序，继续使用原有输入框和按钮的键盘路径。

“重复”是内容提示，不是编辑动作。按每栏的原始字符串精确统计，包含空元素，不修剪空白、合并大小写、展开引用或规范化路径。同组所有成员提示“重复 ×N”；原值栏统计原序列，输入行和新值栏统计当前有效序列，删除项不计入新值统计。未变更的重复项为珊瑚色框；有编辑或移动等变化时保留变更主色，并显示独立重复小标。重复不阻止演示应用、不自动清理。特殊整体字符串不按内部的分号分析重复。图例区分“变更”和“提示”。

上述方向及重复提示已在实施前与 ChatGPT 协作确认。检查覆盖重复产生/解除、重复空项、两栏独立计数、同 ID 双向悬停、输入焦点与悬停优先、内部子节点切换、重绘和关闭清理；仍仅验证演示交互，真实浏览器视觉、缩放和原生拖拽需另行验收。

### 2026-10-13：八处状态与变更标识反馈

负责人实际体验指出恢复默认值仍显示修改，以及元素变更不易区分。本轮将运行修改状态按选定字符串与方案基准值的精确差异派生：初始基准为默认选定值，模拟应用成功后刷新基准。选择同值来源、输入改回或恢复到同一基准值后，待应用计数和输入标记归零；Windows 匹配结果独立计算，不再被修改状态覆盖。界面文案统一为“待应用修改”与“配置修改”。

元素变更沿用稳定行 ID，保存打开时的原始元素序列，按相对顺序区分移动。新增或删除导致的位置平移不会误标为移动。重复值和空项不合并，不按值配对。

- 匹配：可见的浅绿行背景与匹配文字。
- 替换：输入和两侧对应元素同步显示琥珀标识；改回后消除。
- 新增：蓝色小标及轻微输入背景。
- 删除：原值侧与新值侧对照均保留灰色划线及删除标记，不参与实际结果。
- 移动：小型中性标签，移动后再移回消除。
- 将替换：用于工作台与未编辑弹窗的整体替换意图，区别于弹窗本次编辑的替换标识。

前后元素对照包含注释，因此不能作为提交字符串。独立“实际结果字符串”由当前有效行序列化，保留原始空格、重复、空元素与特殊整体值。只有该字符串进入演示应用回调。

新增 15 项状态回归及独立复核通过，覆盖精确差异、同值来源、重复/空项身份、全删除、增删移动、恢复、HTML 转义、实际序列化和替换意图。总计 65 项 DOM 检查；真实浏览器视觉与原生拖拽仍未验收。

### 2026-10-13：自主讨论后的交互修正

负责人授权继续 UI 优化并上传 V3 分支。ChatGPT 基于已上传的实际源码确认本轮范围：只补交互语义，不改核心模型或正式环境执行。当前 Git 分支为 `v3/web-ui-prototype`，网页文件集中在 `ui-v3/`。

- 元素弹窗加入“还原本次编辑”，恢复打开时的完整元素序列，包含空项、重复项及原始空格；不修改演示快照、方案或历史。取消按钮说明丢弃弹窗修改。
- 删除最后一个元素时焦点回到新增按钮。应用、批量勾选、来源选择、配置方案/变量及属性重绘后保留对应焦点；当前对象有 `aria-current` 标识。弹窗打开时页面搜索/导出快捷键不再把焦点带出弹窗。
- 配置草稿统一记录现有四种可编辑属性：默认值、作用域、模式、整体处理。页眉/页脚明确显示属性修改数；修改差异包含四种属性；还原配置覆盖所有方案的这些属性，且不改变运行草稿、演示快照或历史。
- 长标题允许换行或使用提示保留全名，弹窗工具栏在窄窗口换行。维持原有紧凑结构，不新增页面、框架或确认弹窗。
- 额外 13 项 JSDOM 工作流检查通过，报告为 `design-evidence/interaction-report.json`。总计 41 项 DOM 检查。QA 依赖及锁文件只服务开发检查，生产网页依然没有依赖安装和构建要求。
- V3 CI 工作流运行相同 DOM 检查；CI 不替代实际视觉或真实环境验收。
