# Windows 安装包验收

## 2.0.1 可见性修复

2.0.1 修复正式 GUI 经 UAC 提权重启后主窗口不可见的问题。根因是 `ShellExecuteEx` 的 `nShow=0`（`SW_HIDE`）：Qt 主窗口已经创建，但被隐藏。提权启动参数现设为 `nShow=1`（`SW_SHOWNORMAL`），使 GUI 正常显示。

此前 2.0.0 的验收截图只演示了截图流程，没有检查主窗口真实可见性，因此不能证明提权后的 GUI 可见。新的截图验证路径应在捕获截图前检查原生 `IsWindowVisible`，并确认目标 Qt 主窗口可见；仅成功生成截图不足以通过该项。真实 UAC 手工启动结果待本机实际验证后补记，本文件不将其记为已通过。

本次新增原生可见性回归，并重跑权限、首次配置及 Windows 设置入口测试，共 25 项通过。对独立 EXE 使用实际 `ShellExecuteEx` 的 `open` 动词进行无 UAC 的对照：`nShow=0` 时截图校验返回 1 且不生成截图；`nShow=1` 时返回 0 且主窗口可见。构建的独立 EXE 冒烟测试也已通过原生可见性检查。

本机原安装已更新至 2.0.1，安装程序退出码为 0，原个人配置字节保留。更新后启动正式 GUI，并通过 `IsWindowVisible` 确认实际主窗口可见。此次更新辅助进程经过真实 UAC，但由已提升的辅助进程启动 GUI；应用自身再次触发 UAC 的链路依据参数回归和上述 ShellExecute 对照验证，不能等同于用户手工重开验证。
