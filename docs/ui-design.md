# 桌面界面设计

界面采用暖灰画布、墨色文字和少量深绿强调，以平面分区和细线组织工作区。主窗口以批量选择为主，应用清单与当前变量详情并列；配置编辑器按应用、方案和变量组织。字体、颜色和间距来自 `envmanager/theme.py`，规范见 [DESIGN.md](../DESIGN.md)。

## 主窗口

左侧应用清单约 300px，每行约 56px。勾选应用、打开详情和选择方案是独立操作；绿色与黄色状态标记表示已激活和未激活。右侧显示当前变量的来源、选定值与校验信息，参考值默认折叠。底部固定摘要显示本次批次涉及的应用和变量，并提供统一预览入口。

右上角依次提供“环境变量、历史、刷新、配置”。“环境变量”直接打开 Windows 原生设置，使用系统目录中的 rundll32 和 sysdm.cpl，不通过命令解释器。该入口不改写变量；用户在系统设置中修改后可回到管理器刷新。演示界面的该按钮也打开本机真实设置，模拟执行与系统设置入口分别处理。

窄窗口保留应用清单、主操作和工具栏，详情区域可滚动。文字不会因新增入口被挤出按钮。

## 配置编辑器

左侧依次为扁平应用索引、方案选择器和带独立作用域列的变量表。应用、方案和变量标题行右侧均并列提供“新增、删除”；方案选择器下方提供“设为默认方案”。短窗口压缩应用列表的可见行数，保留三组操作入口。

应用概览摘要右侧的方案选择器列出“全部方案”和当前应用的实际方案。具体方案与左侧选择同步；“全部方案”仅切回聚合视图，新增、删除和设默认仍使用左侧的具体方案上下文。单方案也保留选择器，记录表单不重复添加。

表单修改先更新到共享草稿，只有查看差异并明确保存后才写入 TOML。导航守卫保护未更新输入，撤销与重做作用于草稿。选择值和应用环境变量不修改配置定义。

## 视觉与验证

正文 13px，工作区标题 16px，元信息 12px；字体首选 Microsoft YaHei UI，并保留系统 DPI 缩放。间距以 4px 为基数，常用字段和工作区间距为 8px 与 12px。控件共享颜色、图标、键盘焦点与错误状态。

公开截图由 [capture_preview.py](../tools/capture_preview.py) 使用示例配置、MemoryStore 和临时 SQLite 状态生成；内容不来自使用者的个人配置或真实注册表。截图只用于说明界面，不能证明真实系统写入或恢复行为。相关控件、选择和执行边界由 `tests` 中的自动化测试验证。
