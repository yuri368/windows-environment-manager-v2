# 全局匹配、精细撤销、共享保护与方案切换

按应用和方案管理环境变量，并以 Windows 当前原始状态进行只读检测和实际匹配撤销。定义、当前选择、上次成功应用值和历史快照分别维护。

## 配置和元素规则

- 目标为 `(scope, name)`，User/System 独立；变量名不区分大小写，普通值元素区分大小写。
- 所有普通模式按分号拆分，修剪每段首尾 ASCII 空格/制表符，匹配忽略无效空段、重复元素和排列，不展开引用、不解析路径。
- 普通 replace 应用覆盖完整值，完整匹配要求 Windows 与配置有效元素集合相等；配置外元素导致部分匹配。部分匹配仍可撤销实际存在的配置元素。
- 可选布尔字段 `special=true` 位于变量记录，只允许 replace。同一作用域同名目标的全部应用、方案必须统一 special，缺省为 false；配置编辑后重新校验整份配置。
- 特殊值完整原文匹配与写入，分号、大小写、首尾空白、重复内容和空字符串均属于内容；完整匹配时才可整键撤销。

## 检测和五种撤销范围

检测覆盖全部应用、方案和记录，每个目标只读一次。记录提供匹配、缺失、额外元素、重复计数、键存在状态和独立错误；方案显示完全匹配记录数 M/N。所有目标都不存在为尚未配置；键已存在而未全部完整匹配为部分匹配，允许 0/N。

撤销支持单变量、单方案、单应用全部方案、勾选应用各自当前方案、勾选应用全部方案。普通变量只移除配置实际匹配元素，保留配置外内容；撤销后无非空有效元素时删除键。

选定空字符串仅匹配存在且原始值恰好为空的键。主动撤销匹配的唯一空值时删除键；仅执行普通清理时可保留存在且为空的状态。关闭自动整理时，撤销仅移除命中的原始切片，未命中切片的空白、空项、重复和相对顺序原样保留；`" A ;B;; C "` 撤销 B 得 `" A ;; C "`。

## 共享保护与最终预览

保护方为操作范围外应用的全部方案。普通 replace 即使部分匹配也保护当前实际存在的元素；唯一空值按存在且为空的状态保护；特殊值按匹配的完整原文保护。

共享冲突按 `(scope, name)` 分组，组内各元素、空值状态或特殊完整值独立决定，默认保留；全部保留/撤销仅作用于共享项。无共享项直接进入最终预览。用户保留的元素至少保留一份有效副本。

高级设置默认折叠，普通元素首尾空白清理、无效空段清理、大小写敏感去重默认开启。写入整理仅涉及本次目标，不改变检测规则；特殊值不整理，也不检查磁盘路径是否存在。最终预览展示原始状态、最终状态、正常撤销、保留共享项、整理和跳过内容；System 与关键变量删除明确提示风险和权限。

## 切换、事务与历史

方案切换把旧方案匹配元素撤销和新方案应用合成为一次净变更。多个完全匹配旧方案或部分匹配旧方案需要明确选择；共享保留与排序共同决定最终结果。一个事务每目标最多写一次。

同批普通 replace 写入同目标的最终字符串/排列不同（例如 A;B 与 B;A）为冲突；replace 与追加模式同批写同目标也为冲突。执行前冻结配置、选择、共享决策、整理设置和原始状态，写入前再次核对；变化使预览失效。

只读检测不修改注册表、TOML、选择或历史；成功批次才提交上次成功选择。失败回滚和历史恢复按原始快照精确恢复存在性、文本、顺序、重复项、空项和注册表类型，不执行自动整理。无法确认的复杂历史合并保留现有数据并报告冲突。
